## 推荐阅读顺序

1. [概览](./overview.md)：了解框架定位、能力范围和包结构。
2. [快速开始](./getting-started.md)：创建第一个类型化 API，并理解 Router 与 Controller 的选择。
3. [项目与 CRUD 脚手架](./scaffolding.md)：使用 `gin-ninja-cli` 创建项目、app、迁移和 CRUD 代码。
4. [数据、绑定与响应](./data-and-responses.md)：定义请求输入、响应模型、分页、过滤与排序。
5. [中间件与安全](./middleware-security.md)：接入认证、Session、CSRF、安全头、日志、i18n 和上传限制。
6. [高级功能](./advanced-features.md)：使用缓存、API 版本、SSE 和 WebSocket。
7. [使用 TestClient 测试 API](./testing.md)：无需手动组装 `httptest` 即可测试路由和 API。
